# SaaviGenAI Website Content Plan

**Product focus:** SaaviAIDR, AI Detection and Response
**Tagline:** The Key to Secure AI
**Version:** Draft 1, October 2026

## How to use this document

This document lists the content required for every page and section of the new SaaviGenAI website. It includes the written copy, the buttons, the page titles for search engines, and a description of every image or visual.

The following markers are used throughout:

- **[IMAGE: ...]** marks where a visual goes and describes what it should show. The designer replaces each marker with the final visual.
- **[TO CONFIRM]** marks a detail that SaaviGenAI needs to confirm before launch.
- **[PLACEHOLDER]** marks information that will be supplied later.
- **(Button)** marks a call to action.

General guidance for all pages:

- Keep text short. Each section has a headline, at most one or two lines of supporting text, and a visual.
- Use "The Key to Secure AI" in the hero area of the Home page and in the footer only.
- Every page ends with a route to contact.
- Every layout must work on mobile. Multi-column sections stack into a single column on small screens.

## 3.3 Capabilities

**Headline:** What SaaviAIDR does

**Six capability tiles** (icon, title and one line each):

| Capability | Supporting line |
|---|---|
| Auto-discovered AI inventory | See which agents, models, MCP servers and users are active, and label each as approved or under review. |
| Complete activity visibility | Prompts, responses, tool calls, files, model usage and cost, captured for every session. |
| Real-time threat detection | Built-in rules for prompt injection, jailbreaks, data leakage, secret-file access and destructive commands. |
| Behaviour analytics | Baselines for each user and agent flag unusual tools, token spikes and changes in behaviour. |
| AI-assisted alert analysis | Each alert is reviewed with its session context and given a verdict, confidence level and likely intent. |
| Automated response | Playbooks can end sessions, revoke keys or quarantine agents, and can be tested safely before they are enforced. |
